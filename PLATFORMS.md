# Supported platforms

Bluesky is the persona's public social surface: posts, image posts, replies, quote posts, reposts, likes, follows and DMs through AT Protocol. The current autonomous action set does not include proactive profile editing.

Telegram is a private operator channel. Inbound directives require a matching numeric sender and private chat ID. Username matching and group membership are insufficient. No additional social platform is part of the runtime.

OpenRouter supplies text and image review. Kie.ai supplies generated images. GitHub Actions runs tests and production polling and persists encrypted state. Provider availability and actual bills must be checked externally when delivery or billing is uncertain.

See [README](README.md) and [operations](docs/OPERATIONS.md) for configuration, commands and limitations.
