SEO-YEON — PRODUCTION PIPELINE
Read CLAUDE.md first. It holds every rule learned the hard way.

ONE-TIME (done)
  sheet_master.py   reference stack in master/a,b,c   <- identity lives here
  drift_gate.py     ArcFace identity score vs canonical.npy

AUDIT (free, run before every batch)
  audit.py                     reads every prompt, flags known failure modes

OUTSIDE — THE MAJORITY OF THE FEED (Seedream, 1K, no coherence needed)
  outside.py --list           7 places, 29 shots, hairstyle varies per shot
  outside.py --all --budget 3
  drift_gate.py --in content/outside

AT HOME — THE MINORITY (hero + nano banana edits)

PER ROOM (once each)
  hero.py <scene> --n 3        3 candidates, identity refs + room in text
  drift_gate.py --in heroes/<scene>
  hero.py --lock <scene> NN    -> heroes/<scene>.png     THE ROOM IS NOW LOCKED

PER POST (many, cheap)
  session.py <scene>           every frame = an EDIT of the hero
  drift_gate.py --in content/<scene>_session
  realism.py                   grain / chroma / vignette, after the gate

POSTS SHE IS NOT IN (~1 in 4 — cheapest content in the pipeline)
  around.py --mix 6           food, street, details, hands, flatlays, sky
  no identity refs, no drift gate — straight to realism.py

ONE-OFF PLACES (street, shop, gym — nobody expects them twice)
  content.py <scene>           generate normally, no hero needed

VIDEO
  video.py                     Seedance 2.5 / Kling O3. Expensive. Rare.

RULES THAT COST MONEY TO LEARN
  * Never regenerate a recurring room. Edit the hero.
  * Always edit FROM the hero, never from an edit.
  * Short prompts. A reference beats a paragraph.
  * Never describe a room you have attached.
